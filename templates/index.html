Browse opens real Chromium and follows instructions step by step. It will never submit payment. Local only (not on Vercel).

🖱️ Browse mode runs on your own computer

Browse mode needs a real Chromium browser, which this hosted server can't run. It works when you run this app on your own computer:

  1. pip install 'browser-use==1.0.8'
  2. playwright install chromium
  3. Put your free Groq key in .env
  4. Run the app locally and choose Browse

Agent mode uses tools: web search, fetch, weather, news, Wikipedia, calculator, currency, reminders, scheduled tasks, mood suggestions, skills, memory, goals, artifacts, delegation — and browse (with your approval). Examples: Use the daily-briefing skill and brief me. · Tomorrow 11:00 am, check trains to Madurai. · I feel sad.
