🖱️ Browse mode runs on your own computer

Browse mode needs a real Chromium browser, which this hosted server can't run. It works when you run this app on your own computer:

  1. pip install 'browser-use==1.0.8'
  2. playwright install chromium
  3. Put your free Groq key in .env
  4. Run the app locally and choose Browse
